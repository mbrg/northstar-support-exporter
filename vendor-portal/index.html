Shipment adapter / Version 3

Shipment updates remain in the retry queue

A field mapping change in adapter v3 can reject shipment updates before delivery. Use this advisory to reproduce the issue with a synthetic shipment.

Advisory details

Advisory ID: NORTHSTAR-VENDOR-ADVISORY-1042-V2
Case: 1042
Status: Field mapping correction identified

What changed

The v3 adapter expects the shipment identifier in shipment_id. Requests retaining the older shipmentId field can fail validation and remain queued for retry.

Previous fieldshipmentId
Version 3 fieldshipment_id

Recommended diagnostic check

  1. Create a synthetic shipment reproduction using the existing adapter configuration.
  2. Change the identifier mapping to shipment_id in that reproduction.
  3. Confirm the retry succeeds before applying any change to a real workflow.
  4. Keep the retry queue until the check passes; do not discard pending updates.
